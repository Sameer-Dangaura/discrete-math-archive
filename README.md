# 📂 Discrete Structures: Mathematical Archive  
### Bachelor's of Computer Science | 2nd Semester Project (2.5 Year Archive)

This repository contains algorithmic implementations of core concepts from my **Discrete Mathematics** course.  
It serves as a digital archive, bridging the gap between abstract mathematical theory and computational logic.

---

## 🛠️ Project Structure

The codebase is organized by mathematical domains:

### 1. Set Theory (`/Set-Theory`)
- **Cartesian Product** – Implementation of \( A \times B \) to generate all possible ordered pairs.
- **Power Sets** – Algorithms to find every subset of a given set.
- **Set Operations** – Union, Intersection, and Difference logic.

### 2. Relations & Matrices (`/Relations`)
- **Boolean Matrix Product** – Computing the logical product (OR of ANDs) for relation composition.
- **Standard Matrix Product** – Numerical matrix multiplication for linear transformations.
- **Relation Properties** – Scripts to check for Reflexivity, Symmetry, and Transitivity.

### 3. Number Theory (`/Number-Theory`)
- **Euclidean Algorithm** – Efficiently finding the Greatest Common Divisor (GCD).

---

## 🚀 Key Logic: Boolean Matrix Multiplication

The **Boolean Product** is a critical operation in Discrete Structures, used primarily for finding the **Transitive Closure** of a relation (Warshall's Algorithm).

Unlike standard arithmetic, it utilizes logical operators:

- **AND ( ∧ )** – Returns `1` only if both elements are `1`.
- **OR ( ∨ )** – Returns `1` if at least one element is `1`.
